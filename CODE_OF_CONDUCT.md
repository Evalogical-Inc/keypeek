# Code of Conduct

We want keypeek to be a friendly, safe place to contribute.

**Expected:** be respectful, assume good intent, give and take feedback kindly, focus on the work.

**Not acceptable:** harassment, insults, discrimination, personal attacks, publishing others' private information, or pasting real secrets into issues, discussions or pull requests.

**Enforcement:** maintainers may edit, hide or remove contributions and block people who break these rules. Report problems privately through GitHub's "Report content" or by opening a security advisory draft on this repository.

This code applies in issues, pull requests, discussions and any other project space. It is adapted from the spirit of the [Contributor Covenant](https://www.contributor-covenant.org/).
